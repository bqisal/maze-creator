# Maze Creator and Pathfinder (Java)

## 📋 Description
This Java program:
- Generates a random, solvable maze using recursive backtracking
- Finds a path from the start (top-left) to the exit (bottom-right) using DFS (recursively)

## 🧠 Algorithms Used
- **Maze Generation:** Recursive backtracking
- **Pathfinding:** Recursive depth-first search (DFS)

## ▶️ How to Run

Compile:
```bash
javac Main.java MazeGenerator.java Pathfinder.java
```

Run:
```bash
java Main
```

## 📁 File Structure
- `Main.java`: Entry point, connects all components
- `MazeGenerator.java`: Builds the maze
- `Pathfinder.java`: Finds the path
- `README.md`: Documentation

## ✅ Requirements
- Java 8 or above
